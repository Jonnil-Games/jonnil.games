## Added
- Options > Sharing lets you choose what friends can see and how they join. Names are hidden outside the game by default. To share yours, enable Show my name outside the game and select Apply.
- Supported desktop builds can show Discord activity and let Discord friends join the public server when it has room. Choose your settings in Options and select Apply.
- Copy a public server join link from Options. Web builds now recognize invitation links. Installed Windows builds can enable links that open the game. Invitations ask for confirmation before joining, which leaves your session and closes your local server if you are hosting.
- Options now includes See who's online. Visit online.jonnil.games/online to check the public server's player count, capacity and joining availability. If the page cannot open your installed game, start it and use Direct Connect with online.jonnil.games:28080.
- On the online page, enter comma-separated nicknames and enable alerts. Keep the page open. Alerts only cover players sharing their names and match nicknames, not verified accounts.
- Use New Private in the Layers panel when the server allows private layers. Click twice within 10 seconds to confirm. Only your current connection can view and edit it. Rejoining does not restore access, and the server owner can access saved artwork.
- Layer owners can set Editing and Audience in the Layers panel. Setting Editing to Everyone also makes hidden art public. Sharing hidden art requires a second click within 10 seconds. Hiding it later does not erase copies others have seen.
- Use Select and From Canvas to capture up to 256x256 pixels for the Server stamp library. The source must be a public layer everyone can edit. Imported PNGs are excluded, and each server library holds up to 64 stamps.
- Drawing Rules are available in the server console, Host & Play and remote admin controls. Hosts can control stamps, PNG imports, private layers and image placements per connection. Rules save on the server and apply immediately.
- Blocking new stamps or lowering placement limits keeps existing art. Blocking personal PNG imports still allows stamps captured from drawings. Set the placement limit to 0 for unlimited placements. Undo does not restore the allowance.
- Disabling private layers keeps existing private art hidden by default. Hosts can choose to reveal it, but changes that could make it public require a second click within 10 seconds.

## Changed
- The stamp library shows only the Server tab when personal imports are disabled. Pixel-image paste also follows the server's import restrictions.
- Layer votes use a majority of votes cast. Nonvoters do not count, ties leave the canvas unchanged, and votes end early only when remaining votes cannot change the result.
- On updated servers, you can reorder layers you created during your current connection without a vote. You can also archive and restore your private layers without a vote.
- Drawing saves made by this update require an updated server to load. Older drawing saves still load in this version.

## Fixed
- Joining a supported older server retries automatically after a version rejection. Ownership and private layer features are unavailable there. If versions still do not match, the error explains that you need an updated server or a matching game build.
- Switching to the Stamp tool keeps your selection.
- Status and error messages below the server list wrap to fit the available width.

## Security
- Invitation links ignore unrelated startup options included with them.
