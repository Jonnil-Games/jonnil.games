## Changed
- On supported servers, From Canvas in the stamp library now starts a selection when needed. Drag and release to capture, or press Esc to cancel. An existing selection up to 256x256 pixels is used directly.
- The Server tab now appears even when empty on supported servers. The library shows its stamp count and capture limits, including that imported PNGs are excluded.
- Stamp capture instructions and progress stay visible while you select or wait. Errors explain why capture failed, and stalled requests time out so you can try again.

## Fixed
- Camera zoom buttons no longer stop keyboard movement. Dragging outside a zoom control and releasing no longer causes accidental canvas strokes. Typing a zoom percentage still stops movement.
- Fixed unwanted pushes away from flat walls and repeated position corrections while moving around walls online.
- Fixed wall drawing and erasing failing on desktop builds.
- Fixed valid canvas stamps failing to save on desktop. Empty captures no longer add blank stamps to the server library.
- Fixed some valid custom character PNGs failing to load on desktop. Edits made to character artwork outside the game are now recognized.
