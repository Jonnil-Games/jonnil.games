Hello! This is Jonnil. We are introducing a new version of Sticky Paws, fixing a lot of things!
Here is the changelog for the latest Sticky Paws version:

## General bug fixes

- Fixed a bug that caused changed audio settings to not apply when exiting the pause menu.
- Fixed a bug that caused players 2, 3, and 4 to be unable to control the map when playing in multiplayer.
- Fixed a bug that caused thumbnails to not display on renamed custom levels.
- Numerous small bug fixes
- Fixed a rare softlock caused by ground-pounding the chair in the ending cutscene.

## Online

- Added a manual refresh button for the online level/character lists.
- Added pages to online level/character lists to improve compatibility on underpowered devices.
- Fixed a bug that caused level and character thumbnails to not display correctly if the player had to reconnect to the server.
- Fixed a bug that caused the level download process to hang.
- Improved online level/character list stability.

## Quality of life

- Added the button used to pounce to the pounce tutorial sign.
- Centered thumbnails on online level list screen.
- Improved display of in-game achievements.
- Refactored audio system to allow for smoother transitions and more consistent volume.

## Behind the scenes

- Added network error codes for easier diagnosis.
- Cleaned debug logs + removed unused identifiers.
- Improved buffer saving.
- Improved Steam build support (Steamworks path + init fixes)
- Improved translation update/upload checks to prevent freezes.
- Optimized gamepad navigation detection.
- Simplified login/token validation logic.
- Optimized effects to improve thumbnail transparency.
- Standardized online debug logging.
- Updated external links for website rebuild.
- Updated Demo version so it's up-to-date. (The old version hadn't been updated since 2022!)
- Updated project for latest GMS2 beta (replaced deprecated functions, updated camera/data usage)

I hope that you all will enjoy this updated version of Sticky Paws! We've been working very hard on this update, so please enjoy it!
